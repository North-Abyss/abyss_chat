# Abyss Chat Documentation

Welcome to the documentation for Abyss Chat! To make finding what you need easier, the documentation is divided into the following categories:

## 🏛️ [Architecture](architecture/)
Contains technical explanations of how the app works under the hood. Perfect for developers, contributors, and curious users.

- [EXPLANATION.md](architecture/EXPLANATION.md): The core Q&A Interview Guide & Architecture Diagram.
- [Data Storage](architecture/data_storage.md): Explanation of local SQLite storage and AES encryption.
- [Local Signaling](architecture/local_signaling_architecture.md): How mDNS and TCP Socket logic work for offline LAN messaging.
- [WebRTC & TURN](architecture/webrtc_stun_turn.md): How the internet P2P logic and STUN/TURN fallbacks work.

## 📖 [Guides](guides/)
Contains user-facing guides and tutorials.

- [How it Works](guides/how_it_works.md): An explanation of the Dock, main pages, and network limits for end-users.

## 📋 [Meta](meta/)
Contains project planning, versions, and legal documentation.

- [Changelog](meta/CHANGELOG.md): History of notable changes.
- [Release Notes](meta/RELEASE_NOTES.md): Notes for each major release.
- [Next Plan](meta/NextPlan.md): The project roadmap and future plans.
- [Dependencies](meta/dependencies.md): Core third-party packages used in the project.
- [Privacy Policy (Legacy)](meta/PRIVACY.md): The original extended privacy and terms of use document.
